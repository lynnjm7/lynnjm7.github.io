# My Personal Site

This the main repository for my perosnal website. In general, this is a plain
HTML and CSS website. I've tried to make this as simple as possible and
eliminate all of the extra stuff common in modern websites. I decided not to
use any contemporary JavaScript frameworks or static site generators. I've
used some of these tools in the past and I've never been happy with the
result. So, I made the decision to stick with a bare-bones classic web stack
and to bring back the "90s and early-00s web experience" when I restarted
working on this site.

# Running this site locally
In order to properly work on this site, we need to have a simple static
server for our files. The easiest solution for this is to run Python's
static server in the base directory of this site:

```
python3 -m http.server 
```
